## 📖 Sobre

Este repositório reúne as minhas resoluções das listas de exercícios baseadas no livro
**_Algoritmos: Lógica para Desenvolvimento de Programação de Computadores_**, de
**José Augusto N. G. Manzano** e **Jayr Figueiredo de Oliveira**.

É uma **atividade de estudo** do curso de lógica de programação. Os exercícios começam
em entrada, processamento e saída e vão até as três estruturas de repetição.

Cada exercício está em um arquivo `.alg` separado, pronto para abrir e rodar no VisuAlg.

---

## 🗂️ Estrutura

```
manzano/
├── L01*.alg   → Lista 1: sequência e operadores aritméticos
├── L02B.alg   → Lista 1: conversão Fahrenheit → Celsius

└── L05*.alg   → Lista 5: repetição com PARA
```

## 🚀 Como executar

1. Baixe e instale o **[VisuAlg](https://visualg3.com.br/)**
2. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
3. Abra o VisuAlg e vá em **Arquivo → Abrir**
4. Escolha um dos arquivos `.alg`
5. Aperte **F9** para executar ▶️
